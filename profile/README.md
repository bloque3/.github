### Productos y Proyectos Destacados

> Manejamos repositorios públicos y privados según el producto (herramientas para desarrolladores, juegos y plataformas comerciales).

#### ByteLab (`com.bloque3.bytelab`) — *Herramienta dev · Código privado / Docs públicas*
Estación de trabajo móvil **100 % offline** para electrónica digital y arquitectura de computadores: simulador interactivo de compuertas lógicas (EDA), conversor multi-base hasta 64 bits, inspector IEEE-754 de punto flotante y laboratorio de ALU con banderas CCR.

- Repositorio: `bloque3/byte-lab` *(privado)*
- Documentación pública: [bytelab/README.md](https://github.com/bloque3/.github/blob/main/bytelab/README.md)
- Política de privacidad: [bytelab/PRIVACY_POLICY.md](https://github.com/bloque3/.github/blob/main/bytelab/PRIVACY_POLICY.md)

#### Acumulapp — *Producto comercial · Código privado*
Plataforma de fidelización digital mediante tarjetas de sellos y códigos QR orientada a conectar clientes con negocios locales. Incluye app móvil Flutter, backend serverless en AWS SAM (Python + DynamoDB), panel administrativo web y landing en Astro.

- Repositorio: `bloque3/acumulapp` *(privado)*

#### Synapse Labs — *Juego / Simulación · Código privado*
Juego de simulación (*AI compute startup idle tycoon*) offline-first construido en Flutter con diorama isométrico 3D, gestión térmica de racks, flota de GPUs, árbol de I+D y arquitectura hexagonal extensible v2.

- Repositorio: `bloque3/idle-game` *(privado, en proceso de renombre a Synapse Labs)*

#### Agéndate (Appointify) — *Plataforma SaaS · Código privado*
Sistema SaaS para agendamiento y gestión de citas de servicios domésticos e informales con monolito modular en C# (.NET 10), MediatR (CQRS), PostgreSQL, colas asíncronas y portal web en Angular 20.

- Repositorio: `bloque3/appointments` *(privado)*
