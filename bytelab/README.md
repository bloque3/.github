# ByteLab

**Paquete Android:** `com.bloque3.bytelab`  
**Organización:** Bloque3

Estación de trabajo móvil **100 % offline** para ingeniería de sistemas y electrónica digital.

## Módulos

1. **Simulador de Circuitos Lógicos (Canvas EDA):** tablero interactivo con zoom, ajuste a rejilla de 20 px, cableado entre puertos, compuertas estándar ANSI/IEEE (`AND`, `OR`, `NOT`, `NAND`, `NOR`, `XOR`, `XNOR`, `BUF`), interruptores, reloj configurable, `VCC`, `GND`, LEDs y display de 7 segmentos hexadecimal (`0x0` - `0xF`).
2. **Matriz Radix Multi-Base (8 / 16 / 32 / 64 bits):** conversión en tiempo real entre Hexadecimal, Binario, Decimal sin signo, Decimal con signo (Complemento a 2), Octal y ASCII, con matriz interactiva de bits.
3. **Inspector IEEE-754 (32 bits):** desglose interactivo de Signo, Exponente sesgado y Mantisa con evaluación paso a paso y detección de casos especiales (`+Inf`, `-Inf`, `NaN`, subnormales y `+/-0.0`).
4. **Laboratorio de ALU y Registros:** registros duales A y B (8/16/32 bits), 14 operaciones lógicas, aritméticas y rotaciones, con banderas de estado `Z`, `N`, `C`, `V` y `P`.
